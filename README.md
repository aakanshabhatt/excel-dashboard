📌 Project Overview
Transformed raw sales data into an interactive Excel dashboard to identify growth opportunities for a multi-channel clothing retail store.

🛠️ Tech Stack
Excel: Pivot Tables, Slicers, Advanced Formulas, Data Cleaning.

💡 Key Insights
Top Demographic: Women contribute 64% of total revenue.

Leading Channel: Amazon is the top platform with 35% market share.

Highest Sales State: Maharashtra (₹2.99M).

Core Audience: Adults (30-49 years) are the most profitable segment.

🚀 Recommendation
Focus marketing spend on Amazon/Myntra and target women in Maharashtra to maximize 2025 ROI.
